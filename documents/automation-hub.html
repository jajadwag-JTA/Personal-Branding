Project 03 · Business Process Automation

Automation Hub

A collection of practical automation solutions designed to reduce repetitive work, introduce controlled workflows and improve the reliability of business operations.

Python Django React SAP Integration Workflow Automation

Project Profile

What it does: The Automation Hub brings together business process automation solutions that streamline recurring financial administration and document-handling workflows.

Why it was developed: Repetitive manual activities can consume staff time, create avoidable processing delays and make it harder to maintain consistent records. The hub explores how structured workflows, validation and system integration can address these challenges.

How it works: Each solution takes defined business inputs, applies processing and validation rules, interacts with relevant business systems where configured, and records outcomes for review.

Business value: The solutions aim to reduce manual effort, improve process consistency, strengthen traceability and give users clearer visibility of exceptions requiring attention.

Automation Solutions

#1 — Recurring Invoice Automation

Development and testing stage

Purpose: Streamlines the preparation and controlled processing of recurring monthly supplier invoices.

Workflow

  1. Configure reusable invoice templates with supplier, expense, accounting and schedule details.
  2. Generate invoices for each due period while preventing duplicate records for the same template and period.
  3. Route pending invoices through an approval process with role-based access controls.
  4. Synchronise approved invoices with SAP Business One through an integration workflow.
  5. Record actions in an audit trail and track notification and processing failures.

Technology: Python, Django, React, Vite, SAP Business One Service Layer and SAP HANA.

Implemented features: Authentication and user roles, recurring templates, invoice generation, duplicate prevention, approval controls, audit logging, email records and dry-run synchronisation.

Current status: Core workflows have been developed and tested in a development environment. A successful SAP invoice-posting test, production configuration and hosting remain outstanding. The first posting test did not create an invoice.

#2 — Delivery Invoices

Development testing completed; production transition pending

Purpose: Automates the matching of digital delivery-proof documents to their corresponding delivery records in an enterprise system.

Workflow

  1. Scan a designated document folder for delivery-proof PDF files.
  2. Extract a delivery reference from each filename using a defined matching rule.
  3. Compare the reference against eligible delivery records.
  4. Classify each document for processing, skipping or manual review.
  5. For eligible records, update the configured document-link field through the SAP integration.
  6. Read back the updated value to verify the result and produce processing reports.

Technology: Python, SAP Business One Service Layer, SAP HANA and automated reporting.

Development test results: A documented test covering 4,200 PDFs classified 11 for attachment processing, 4,154 as skipped and 35 for review. The 11 attachment attempts were refused by an SAP validation rule and were not successful attachments.

Current status: Document scanning, matching, classification, integration and verification workflows have been developed and exercised in a development environment. Production deployment and resolution of the reported SAP validation issue remain outstanding.

Design Principles

  • Controlled processing: Use defined rules and approval steps for sensitive business operations.
  • Validation: Check inputs and system responses rather than assuming a successful operation.
  • Traceability: Retain processing outcomes, audit information and exception details.
  • Exception handling: Separate records that can be processed from those requiring human review.
  • Incremental delivery: Develop and test integrations before considering production use.
